## Gotchas already hit (do not rediscover)

- **Tailwind v4 needs `source(none)`** plus explicit `@source` globs, or it scans the wrong tree.
- **Dynamic class strings must be full literals** in PHP or JS. Never assemble from fragments; the scanner
  will not see them. That is why `dfi_status_badge_class()` etc. return whole strings.
- **Hidden `required` fields silently block form submission.** `contact-form.js` sets `disabled` on inactive tab
  groups, which also keeps them out of `FormData`. Do not "simplify" this away.
- **Do not use PowerShell `Compress-Archive`** for the theme zip: it writes backslash entry names that Linux hosts
  unpack as literal filenames. Use `python package.py` (in `wp-theme/`), which writes forward slashes.
- **`lucide-react` alias modules**: some icon files just re-export another (`check-circle.mjs` to
  `circle-check-big.mjs`). `gen-icons.mjs` follows the alias.
- The REST nonce assumes no full-page cache plugin. None is installed today. If one is added, exclude `/contact/`
  or drop the nonce and rely on the honeypot plus rate limit.
